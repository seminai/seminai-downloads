# Seminai

Distribuzione gratuita di Seminai per macOS, Windows e Linux.
Il client si collega a [app.seminai.tech](https://app.seminai.tech), con lo stesso
account e gli stessi dati del browser sul servizio Core.
Pagina di presentazione: [download.seminai.tech](https://download.seminai.tech).

## Stato della distribuzione

Edizione in preparazione. Non sono ancora disponibili installer pubblici Cloud.
La pubblicazione richiede il completamento delle verifiche tecniche. I
[termini dell'edizione gratuita](TERMS.md) sono disponibili.
Questa repository contiene esclusivamente materiale pubblico di distribuzione; non contiene
il repository di sviluppo, backend, dataset riservati o chiavi.

La nuova edizione usa un profilo separato dalle installazioni locali precedenti e non ne importa i dati.
Le note di ogni release indicano sistemi supportati, checksum e stato effettivo delle firme,
generato dalle ricevute allegate (notarizzazione Apple, Authenticode Windows, firma GPG del
manifesto `SHA256SUMS.txt`). Una firma è dichiarata solo quando verificata.
